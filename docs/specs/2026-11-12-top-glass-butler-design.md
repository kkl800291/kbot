# 顶部柔光衬底与能量管家

日期：2026-11-12（同日修订：外壳从玻璃面板改为柔光衬底；再修订：取消羽化的柔光衬底，见下）

> **再修订（以此为准）**：羽化的柔光衬底在浅色外观叠深色桌面时是一大块脏灰，已取消。下文凡提到“羽化”“柔光衬底”“衬底比内容区大一圈”的地方，都按这里理解：
>
> - **底板**：一律是边界清晰的圆角矩形，92% 不透明的均匀底色加 0.5px 发丝线，投影画在底板外，不羽化（`feather` 恒为 0）。对话窗口和通知圆角 18，探出和常驻条圆角 14，底板就是内容区本身。
> - **召唤态**：没有整块底板，能量体直接浮在桌面上。只有一张 432 宽、圆角 22 的小卡片垫在输入框下面（高 44）；有字幕时卡片向上长高，字幕在上、输入框在下。
> - **能量体画法**：召唤态背后可能是任何颜色，固定用不透明画法并自带外晕；其余状态在底板上，跟系统深浅。
> - **能量体形象**：一个正圆的、从内向外发光的球体，内部是大块缓慢流动的色团；所有状态共用这一个身体，靠姿态（弹簧、挤压拉伸、目光）区分，粒子只是身体周围的气息。瞬间动作和出错时允许短暂变形。

KBOT 不再是桌面上到处待着的小机器人。平时屏幕上什么都没有；有事时，屏幕顶部中央浮现一团粒子能量体和要说的内容。它周围一圈背景被柔和地模糊、压暗（浅色外观下是提亮），越往外越淡，最后融进桌面。没有边框、没有面板，这圈衬底只用来把能量体和文字托出来。人设随之改成英式 AI 管家的口吻。

原型：`prototype/energy-lab.html`（深浅外观、各状态下的能量体和接口）。早期的 glass-demo、energy-demo 等演示页已删除。

## 目标

- 平时完全不占屏幕，不挡工作；通过快捷键、鼠标停留或主动提醒出现。
- 衬底模糊后面真实的窗口和桌面，不管后面是深是浅都能把内容托清楚；在所有桌面和全屏应用里都能出现。
- 角色形象是一团会变形的能量体，思考、说话、提醒、执行任务各有不同形态，不再是固定的五官和身体。
- 说话口吻是沉稳得体的管家，称呼默认用“您”。
- 现有对话、提醒、休息倒计时、感知、快捷键的能力都保留。

## 非目标

- 不做 Spotlight 那种不激活的浮动面板。展开对话时系统菜单栏会切成 KBOT 的，这一版接受。
- 不分析真实语音振幅，说话形态用模拟的音节起伏。
- 不改提醒的触发时间和条件、语音合成、模型调用和 DSH。
- 不实现“习惯记忆与人格偏移”（见 2026-11-10 的设计）。它沿用的四个性格键名不变，以后可以直接接上。
- 不支持 macOS 以外的平台。

## 一、顶部柔光衬底

### 窗口

- 主窗口（标签仍为 `main`）不再铺满屏幕，改成屏幕顶部中央一块 1000×740 的透明区域：最大的展开对话内容 760×620，加离顶边 8 和衬底羽化的余量。顶边贴着屏幕顶边。启动时在主屏。
- 有刘海的屏幕上，内容顶边放到刘海下方，用系统给出的顶部安全区高度。
- 窗口层级高于菜单栏（`NSStatusWindowLevel`），弹出菜单仍在它之上。集合行为：出现在所有桌面、可以出现在全屏应用上、不参与窗口切换。
- 托盘“移到鼠标所在屏幕”沿用，显示器变化时重新定位到当前屏幕顶部中央。
- 窗口内的层次，从下到上：
  1. 原生衬底视图：`NSVisualEffectView`（透出窗口后面），配一张边缘渐变到透明的遮罩图做羽化。液态玻璃（`NSGlassEffectView`）的边缘是硬的，不用。
  2. 透明的网页，放能量体画布和文字。
- 网页决定衬底此刻的矩形和羽化宽度，通过一个命令交给原生层；原生层把衬底视图和遮罩动画到目标。
- 只有内容区接收点击，羽化的外圈和其余透明部分全部点击穿透，沿用现有的区域上报和鼠标轮询。
- 第三步动手前先做一个原生小验证：系统模糊视图能不能接受半透明的遮罩、做出羽化。不行就改用图层遮罩（渐变图层）。

### 衬底在深浅背景上都要清楚

- 外观跟随系统：深色模式用深色材质，文字白色，能量体发光叠加；浅色模式用浅色材质，文字深色，能量体改成颜料画法（见“二、能量体”）。系统外观切换时实时跟着变。
- 衬底不是简单叠一层半透明的黑或白，而是先压缩背景的明暗对比再着色。这样不管后面是深色编辑器还是白色文档，衬底核心都落在同一段很窄的亮度里，文字和能量体下面的底色稳定。系统材质本身就是这样做的；网页兜底用 `contrast()`、`brightness()` 加着色近似。
- 衬底比内容区大一圈：左右和下方各多出羽化宽度 f = 0.35 × 内容短边 + 30，限制在 44 到 130 之间，并且不超出窗口。外圈从实到透明分段渐变；顶边贴着屏幕顶边，不羽化。
- 能量体不受衬底裁切，“完成”的爆散可以飞出衬底。
- 对话窗口是一块清晰的面板，不用柔光：要读大段文字，无边界的羽化会在深色背景上变成脏晕影，消息区、输入框、外圈三块明暗不一。
  - 衬底矩形就是内容区（离顶边 8，有刘海加安全区），圆角 18，不羽化，只留 1 像素抗锯齿；其余状态圆角为 0，羽化照上面的规则。`set_backdrop` 多一个圆角参数，从其他状态进出窗口时，矩形、羽化、圆角按同一条曲线一起变。任何状态下衬底都不超出窗口，纵向也一样。
  - 系统模糊视图上，网页再铺一层 92% 不透明的均匀底色（浅色 #F4F4F6，深色 #1E1E20）加 0.5px 发丝线，后面的内容只透出一点点；投影由网页画在面板外。
  - 面板里的输入框、卡片、步骤胶囊、代码都和面板同一色系：输入框是略抬高的半透明白（深色是 6% 白）加发丝线，其余是 5% 左右的中性淡填充。

### 六个状态

下表是内容区的大小，衬底按上面的规则比它大一圈。召唤态是智能体本身，以它为主；对话窗口是另一个入口。

| 状态 | 内容区（宽×高） | 内容 |
|---|---|---|
| 隐身 | 不显示 | 无 |
| 探出 | 340×40 | 当前时间 + 一行状态：有进行中的事就显示那件事，否则显示连续专注时长和下次休息时间 |
| 常驻 | 280×40；出错 300×40；任务 340×52 | 进行中的事：后台任务（身体在左，进度带沿底边）、朗读、后台思考、出错重试、休息倒计时 |
| 通知 | 440×116 | 标题、正文、最多两个按钮 |
| 召唤 | 就绪 480×220；有字幕时随字幕长高，最高 360 | 能量体是主角（框 220×160），下面是字幕和输入胶囊 |
| 对话窗口 | 常规 540×440；展开 760×620 | 能量体退成头部左侧 40×40 的头像，下面是消息和输入框 |

- 内容区居中，离顶边 8。
- 召唤态：
  - 字幕在能量体和输入胶囊之间：一行您刚说的话（12px，单行省略），下面是回复（15px，最多 4 行）。一行居中，多行左对齐；流式输出时新追加的文字淡入。
  - 字幕是回复的纯文字：markdown 去掉格式，代码、图片、表格不显示。超过 4 行截断；截断或回复里有字幕放不下的内容（代码、图片、表格、提问卡、工具审批、出错）时，给“在窗口中查看全文 ›”，点它打开窗口并定位到这条回复。
  - 输入胶囊 432×44，只有极淡的填充和发丝内描边，聚焦时描边换成强调色。Enter 发送；⌘↩ 或右侧按钮“在窗口中继续”，带着没发出的文字进窗口。回复中可以打字但不能发送，右侧按钮变成停止。没有卡片底色、边框和头部工具栏。
  - 和窗口是同一个对话（`A.chat.cur`），走同一条发送管线。
  - 能量体：就绪和输入时倾听（每个按键起一次波），发送后思考，出字时说话，结束回到倾听；表情标签照常生效。
- 变大用 0.54 秒、带轻微回弹的曲线（`cubic-bezier(.32, 1.32, .52, 1)`），变小用 0.36 秒（`cubic-bezier(.4, 0, .2, 1)`）。衬底的大小和羽化宽度一起变。原生层用同样的时长；如果系统动画不接受回弹曲线，就用阻尼弹簧，调到 0.54 秒内停稳。
- 文字在衬底开始变形 0.2 秒后用 0.26 秒淡入，切走时先用 0.14 秒淡出。因此两边动画只需要大致同步。
- 收起顺序：有进行中的事就回到常驻，否则隐身。

### 唤起与不打扰

- ⌥Space（沿用设置里的快捷键）召唤 KBOT，进召唤态；召唤态或窗口里再按一次就收起。Esc 收起。打开“点外面收起”时，点内容区以外的地方也收起。
- 召唤态里回复结束后，30 秒没有悬停、没有输入、输入框为空，就自动收起。
- 召唤态或窗口收起时还在回复，留一条“正在回复…”常驻条，并记下这段回复最后是在哪里看的。
- 对话窗口的入口：召唤态的“在窗口中继续”（⌘↩）和“在窗口中查看全文”；菜单栏图标菜单和右键菜单的“打开对话窗口”；托盘的“打开对话窗口”；把图片拖到 KBOT 上；指向某段对话或需要富交互（如提问卡）的通知；截图提问截完后。
- 顶部中央一条 300×6 的感应区。鼠标在里面停 0.4 秒才探出，离开 0.45 秒后收回。感应区不拦截点击，靠现有的鼠标位置轮询判断，菜单栏中间照常可点。
- 点探出条进召唤态。点常驻条：那件事来自窗口里的对话就回窗口，否则进召唤态（正在回复时字幕接着显示）。
- 右键常驻条弹出菜单，开头三项是“召唤 KBOT”（已召唤时为“收起”）、“打开对话窗口”、“新对话”，其余不变。菜单栏图标菜单和托盘菜单都有“召唤 KBOT”和“打开对话窗口”两项。
- 主动提醒、陪伴话、“回来啦”都以通知状态出现，展示时长沿用现在的时长（提醒 12 秒、陪伴话 8.5 秒）。鼠标停在通知上就不收起。同时只显示一条，其余排队。陪伴话出现时，能量体先“开口”说一会儿（字数 × 60ms，0.8 到 3 秒），再回到待命。
- 通知并入召唤态：召唤时正在显示的通知变成字幕，按钮保留，倒计时停止；排队的只取最新一条，其余记进当前对话。点通知正文也是这样进召唤态。召唤态里来的通知：没在回复就直接成为字幕，正在回复就排队，收起后再出。
- 离开、勿扰、会议中不弹通知，和现在一样。
- 通知到点时，如果最近 2 秒内有键盘或鼠标操作，就等空闲满 2 秒再出现。有通知在等时，空闲时长每秒读一次。陪伴话等超过 10 分钟就作废；提醒一直等。
- 托盘“显示／隐藏伙伴”改名为“显示／隐藏 KBOT”。隐藏后感应区和通知都关掉，⌥Space 仍能召唤。

### 焦点

- 隐身、探出、常驻、通知都不拿焦点。
- 召唤态和对话窗口拿焦点（分别聚焦输入胶囊和窗口输入框），两者都收起后把焦点还给原来的前台应用，沿用现有的 `focus_companion` 和 `release_focus`。两者之间切换不归还焦点。

## 二、能量体

### 模块

- 删除现在的机器人绘制代码，新写一组 `energy-*.js`：
  - `energy-forms.js`：各形态的目标位置；
  - `energy-attractors.js`：四个混沌吸引子；
  - `energy-sim.js`：粒子跟随和颜色；
  - `energy-gl.js`：WebGL 绘制；
  - `energy.js`：对外接口。
- 对外接口：`setMode(mode)`、`accent(expression)`、`setBox(rect)`、`setPalette(name)`、`setTone('dark' | 'light')`、`setProgress(p)`、`kick()`（打字时起波）、`setReduced(bool)`、`start()` / `stop()`；另有 `renderStill(canvas, …)` 给小图标画静态帧。
- 2400 个粒子，位置每帧在 CPU 上算，WebGL 只画点。常驻条里只画 30%，进度带用全部粒子。
- 深色外观绘制三层：淡暗影托底，大而淡的光晕（叠加混合），清晰粒子（叠加混合）。浅色外观改成颜料画法：正常覆盖混合，只用色阶偏深的一半再压暗一点，不画暗影。
- 画布和窗口一样大，能量框用窗口坐标；衬底伸缩时画布不用重新分配大小。
- 只在衬底可见时模拟和绘制。隐身时停掉动画循环，画布清空。

### 形态

| 模式 | 形态 | 什么时候 |
|---|---|---|
| 待命 | 能量丝球、旋臂星云、流光环结，约 25 秒换一种 | 没事的时候 |
| 倾听 | 三股光带，打字时从中间向两边起波 | 对话展开、等待输入 |
| 思考 | 四种混沌吸引子之一（Aizawa、Thomas、Lorenz、Halvorsen），每次进入换一种 | 等模型回复、后台思考 |
| 说话 | 光带或环形声波，随音节起伏 | 流式输出回复、朗读 |
| 提醒 | 向外扩散的脉冲环，转成警示色 | 提醒类通知 |
| 执行任务 | 沿内容区底边的进度带，前沿最亮 | 后台任务、休息倒计时 |
| 完成 | 爆散一次，1.1 秒后回到待命 | 任务完成通知 |
| 出错 | 错位闪烁，转红 | 出错重试 |

- 能量体所在的框随状态变化：
  - 对话：顶部一条，高 132；
  - 通知：左侧 88×88；
  - 常驻：左侧 26×26；
  - 任务：底边一条，高 8。
- 粒子位置按框的短边归一化，并约束在框的宽高比范围内。从隐身出现时，从顶部中央一个小点长出来。
- 切换模式时带一次旋转过渡，粒子从当前形态流向下一个。宽框里旋转先按宽高比压扁，避免进度带歪成斜线。

### 情绪

回复里的表情标签给当前形态叠加 1 到 3 秒的情绪，不切换模式：

| 标签 | 效果 |
|---|---|
| `happy` | 整体亮一下，略微膨胀 |
| `surprised` | 小幅爆散后收回 |
| `confused` | 粒子松散，旋转反向一下 |
| `sad` | 变暗、变慢、往下沉 |
| `sleepy` | 变暗，呼吸变慢 |
| `annoyed` | 收紧，偏红 |
| `think` | 切到思考模式，直到下一段回复文字开始输出 |
| `remind` | 切到提醒形态 3 秒，再回到原来的模式 |

`wink`、`coy` 从可用标签里删掉，但仍会从文字里剥离，按 `happy` 处理，避免旧工作区的提示词让标签漏进回复。朗读的情绪映射同样把这两个当作 `happy`。

### 配色与设置

- “强调色”改为能量体配色：熔金（默认）、极光、虹彩。旧值（蓝、靛、橙、绿）一律换成熔金。
- 界面强调色不取能量体的发光色，按配色和深浅各挑一个（`src/ui/accent.js`），浅色版配白字、深色版配深色字，链接和主按钮文字都过 WCAG AA。强调色只用在链接、聚焦描边、主按钮、发送按钮、选中态这类小面积元素；用户气泡是带一点强调色倾向的中性色（12%，深色 18%），文字不反白。

## 错误处理与兜底

- 系统模糊视图不接受半透明遮罩：改用渐变图层做遮罩。
- 原生衬底创建失败：网页里画一块羽化的衬底顶替，核心 92% 不透明（深色或浅色随外观），看不到后面的窗口，其余功能不受影响，并记一条日志。
- WebGL 不可用或上下文丢失：能量体换成一帧静态图，按状态缩放；上下文恢复后重建。
- 窗口定位失败或显示器变化：回退到主屏顶部中央。
- 通知排队超过 5 条：丢掉最早的陪伴话，提醒不丢。
