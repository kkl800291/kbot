# KBOT · macOS 开发预览

基于需求 v0.6 与 Claude 的交互原型，使用 Tauri 2 + TypeScript + Canvas + Rust。`prototype/` 保留为设计参考；正式应用从根目录 `index.html` 与 `src/main.ts` 启动。

正式名称为 **KBOT**。应用图标母版、横版品牌封面与生成提示词见 [`assets/branding/`](assets/branding/README.md)；系统图标资源由母版生成，打包使用 `src-tauri/icons/`。

v0.1.6：失焦后的角色悬停统一由原生鼠标采样驱动，移入即可显示设置／勿扰，离开后收起，跨过角色与按钮之间的间隙不会误关；快捷按钮出现时立即同步原生点击区域。主动发言与提醒完整传入模型上下文，点击角色或气泡进入时保留开场白并持久化；陪伴对话中普通接话不再强制关键词搜索，明确查资料或实时信息时仍可联网。

v0.1.5：启动只查询钥匙串凭据元数据，不读取 API Key 或主动弹授权；钥匙串查询、保存和删除在后台线程执行，等待系统授权不再阻塞窗口交互；删除凭据不再先读密钥，拒绝授权时给出对应原因而不误报 Key 丢失。当前仍为临时签名测试版，跨版本首次真正使用 Key 时仍可能请求 macOS 授权；免重复授权需要持续使用固定的正式代码签名身份。

v0.1.4：角色开关统一在完整 click 事件后执行，避免 pointerup 中切换原生焦点；原生鼠标采样携带采样时间，延迟的松手事件不再取消新点击；忽略旧一轮指针捕获丢失事件，禁用主 WebView 的后台挂起。日常陪伴独立于工作时长与工作日，安静／适中／话多约每 15–25／3–5／1.5–2.5 分钟出现；按性格、时段和已开启的应用类别轮换本地话题，不连续重复。聊天、设置、勿扰、拖动、休息和已有气泡时让开，忽略气泡仅放慢而不永久停说；连续空闲 5 分钟才休眠，工作计时规则保持独立。

v0.1.3：修复原生角色点击仍可能落到透明背景的问题：启用 macOS 未激活窗口接收点击，原生模式的点击范围统一交给原生穿透区域管理，不再等待网页悬停状态；每次有效点击都展开／收起对话，连击只切换表情，不再吞掉开关动作或弹出气泡；支持辅助功能点击；设置的“通用”页显示当前进程版本。可通过 `COMPANION_INTERACTION_TRACE=1` 临时启用本机交互诊断，仅记录事件类型和窗口状态，不记录输入文字、聊天或 Key。

v0.1.2：恢复 Dock 图标与点击打开聊天；补齐 DeepSeek 官方搜索、OpenAI／Grok Responses 联网和自定义联网格式，展示实际搜索状态和可点击来源；对话模型与看图模型改为从当前服务 API 读取的下拉列表，支持刷新和手动填写；修复连续点击、丢失指针捕获、切换焦点后的角色交互状态与点击穿透恢复。

v0.1.1：设置改为独立的原生窗口，支持标题栏拖动、窗口缩放、红色关闭、黄色最小化和绿色进入／退出全屏。关闭只隐藏设置窗口，可从菜单栏再次打开；机器人和提醒一直由主窗口运行。设置页通过字段差分同步给主窗口，不单独启动计时器或覆盖本地数据文件。

## 运行与打包

需要 Node.js 22.12+、Rust stable、Xcode Command Line Tools。当前产物为 Apple Silicon 版本。

```sh
npm install
npm run desktop        # 原生开发应用
npm run desktop:build  # .app 和 .dmg
npm run dev            # 浏览器检查界面，原生能力不可用
npm test
cargo test --manifest-path src-tauri/Cargo.toml --lib
```

`npm run desktop:build` 完成后，DMG 安装包自动复制到项目根目录（例如 `KBOT_0.1.6_aarch64.dmg`）；Tauri 中间产物仍保存在 `src-tauri/target/release/bundle/`。开发脚本会将当前用户的 `~/.cargo/bin` 加入子进程 PATH，不修改系统或 shell 配置。首次编译需下载 Rust 依赖。

## 已实现

- 透明置顶窗口、菜单栏、单实例、显示与隐藏、原生鼠标位置采样、角色区域与面板区域的点击穿透、全局聊天快捷键、开机启动。
- 复用原创机器人的 16 种表情、连续变形、拖动反馈、深浅色界面与减少动态效果。隐藏角色后停止绘制。
- 首次使用引导；感知开关；通过 macOS 空闲时长累计工作时间，离开达到休息时长后清零；通过前台应用名称识别会议应用。
- 本地休息、喝水、护眼、用餐、下班、深夜、早安、生日与日期提醒；自定义一次性／每天／工作日／每周／每月提醒；确认卡、延后、跳过和勿扰。
- 日常陪伴与提醒分别使用每小时预算，提醒之间至少五分钟、陪伴按频率轮换；勿扰后只补最近一条有效的中优先级提醒；睡眠／长时间离开后合并高优先级提醒。
- 原生每秒事件驱动调度，避免隐藏 webview 后浏览器定时器被节流；本地 JSON 原子替换保存；重复提醒按当地日历排期。
- OpenAI 兼容 Chat Completions：真实 SSE 流式回复、停止与重试、Markdown、历史管理、模型工具调用产生提醒／记忆草案。确认后才保存；模型配置支持关闭工具调用。
- 图片粘贴／拖入／选择、本地压缩、独立看图模型；macOS 授权后的系统区域截图。HEIC 解码取决于系统 WebKit，失败时提示改用 PNG/JPG。
- API Key 通过 Rust 直接写入 macOS 钥匙串，不回传前端，也不写入 JSON。模型配置页有真实文本与图片连接测试。
- DeepSeek 官方 Search API（复用对话 Key）、OpenAI／Grok Responses `web_search`、通义兼容接口联网和 Tavily／Brave 搜索；自定义服务可指定联网格式。搜索状态以服务实际返回为准，来源链接通过系统浏览器打开；失败时显示原因，不静默退回离线回答。搜索及服务商托管工具可能按对应服务规则单独计费。
- 对话与看图模型通过当前服务的 `/models` 接口读取下拉列表；模型权限和工具能力取决于服务商与账户，可在设置中分别测试连接和联网搜索。不提供兼容模型列表的服务可手动填写模型 ID。
- Open-Meteo 城市查询、天气与缓存；本地农历、节气和节假日表（来自 `lunar-javascript`）。

## 当前边界

这是第一轮开发预览，不是需求 v0.6 的完整发布版。

- 日历 EventKit 读取、会议前提醒、演示／全屏播放检测与 macOS 专注模式跟随尚未接入；设置中标识了日历暂不可用。会议应用名称检测已经可用，但不能等同于判断实际正在开会。
- 自动提醒目前使用本地话术；AI 已用于聊天、提醒解析和记忆草案，尚未用于改写每条主动提醒。
- 多屏有“移到鼠标所在屏幕”和断屏回收；跨屏连续拖动、不同 DPI、所有全屏空间及中文输入法候选框仍需真机专项验证。
- 原生点击穿透使用角色近似轮廓和面板矩形，夸张动作的极小边缘可能与绘制轮廓不完全一致。
- 节假日表覆盖范围由锁定的日历依赖决定，尚无在线年度更新；公历与农历生日已实现，闰月生日单独配置及批量导入未提供。
- 自然语言提醒依赖支持工具调用的模型；不支持时可关闭工具调用并手动添加提醒，尚无结构化文本回退解析。
- API Key、联网搜索、通知、截图和开机启动需在桌面应用使用；浏览器预览仅持久化界面调试数据。
- 本机构建未进行 Developer ID 签名、公证和自动更新，不用于公开分发。Intel 构建和最低系统版本尚未真机验证。
- 动画长期资源占用、系统睡眠／唤醒、全屏和多屏需要持续试用，不将短时冒烟测试当作完整验收。

## 数据与隐私

- 配置、提醒、记忆和对话：`~/Library/Application Support/com.cybercompanion.desktop/state.json`，文件权限 `0600`，先写临时文件并同步，再原子替换；损坏数据保留 `.recovery` 副本。
- API Key：macOS 钥匙串服务 `com.cybercompanion.desktop`，按 `chat`、`vision`、`search` 分别保存。
- 没有应用业务服务器、账号或遥测。模型与搜索通过 Rust 请求用户指定／配置的服务，凭据不跟随 HTTP 重定向。HTTP 仅允许本机模型地址。
- 图片只在用户主动添加后发送；截图临时文件读取后删除；不后台读屏、读取窗口标题或监听剪贴板。
- 当前前台应用具体名称默认不发给模型；记忆按问题关键词筛选少量相关条目。
- “清除所有数据”也会清除这三个钥匙串凭据。

## 验证记录

`tests/scheduler.test.ts` 覆盖日历排期、月末与闰年、日期校验、实际工作时间、空闲／睡眠、休息清零和主动发言预算。Rust 单元测试覆盖透明区域边界与凭据传输地址校验。

开发专用原生冒烟测试使用独立 bundle ID、数据目录和钥匙串服务，接入 `scripts/native-fixture.mjs` 的本机接口，验证分段 UTF-8 SSE、分段工具调用、停止请求、401 错误、本地持久化、隐藏窗口后的提醒调度和关闭面板后的 `inert` 状态，不访问真实付费模型。

运行方式（先启动 `npm run dev`）：

```sh
node scripts/native-fixture.mjs
# 另一个终端，先确保 cargo 位于 PATH：
COMPANION_SMOKE=1 TAURI_CONFIG='{"identifier":"com.cybercompanion.development"}' cargo run --manifest-path src-tauri/Cargo.toml
```

结果写入系统临时目录的 `companion-native-smoke.json`。验证进程会自行退出。发布构建禁用开发测试入口。
